# 🏸 Development of Badminton Court Booking System for GOR Sigumpar

A simple online court reservation system for GOR Sigumpar, built to help users book badminton courts easily via web and Android app. It also helps admins manage schedules and payments more efficiently.

## 📝 Background Problem
Manual scheduling and paper-based booking systems at GOR Sigumpar led to frequent double bookings, scheduling confusion, and customer inconvenience. This app solves that by providing:
- Digital reservation system
- Real-time schedule updates
- Manual payment verification workflow
- Better transparency and user experience


## 🛠️ Tech Stack

- 🌐 Laravel (Website Backend)
- 🍃 MongoDB (Database)
- 📱 React Native (Android App)
- 🎨 Figma (Design & Wireframe)
- 💻 VSCode (Code Editor)


## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/gor-booking-system.git
cd gor-booking-system
```

### 2. Setup Laravel Backend
```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```
Make sure to update .env with your database and app settings.

## 📱 Features
👤 For Users
- Login & Register
- Book courts online
- Check court availability
- Upload payment proof
- Join/Host Main Bareng (Play Together)
- View & join events/tournaments
- Edit profile & booking history

🛠️ For Admins
- Manage booking schedules
- Confirm payments
- View transaction reports
- Update GOR info (address, facilities, etc)

## 📝 Notes
- 💵 Payments are currently manual (bank transfer or cash)
- 📱 Mobile app available only for Android (iOS coming soon)
- 🧑‍💼 Admin verification may take time (1-person team)
